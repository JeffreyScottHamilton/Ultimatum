# Coding discipline: what is not covered here, and where to go

Read when a topic from the Karpathy-style guidelines seems missing and you want to know whether it lives elsewhere in Ultimatum.

- **Editor-specific rule files** (a `CURSOR.md` or similar): Ultimatum ships as a Claude Code plugin; the same rules apply through the Work skill.
- **A translated README:** not needed for guidance.
- **The upstream examples file:** not read, because the repository has no LICENSE file. Our own examples are in `smallest-change.md` § 3. Worked example and the tables in `think-first.md` and `checkable-goals.md`.
- **Simplicity ladder and per-task stop rules:** `../caveman/task-stances.md`.
- **Debugging method:** `../../debugging.md` and `../superpowers/debugging-moves.md`.
- **Test-first mechanics:** `../../tdd.md`.
- **Planning larger work:** `../../feature-planning.md`.

If the upstream adds a LICENSE file, compare it against these files and record what it covers that we do not.
