# Decks craft: index

Read when the task is a slide deck: an investor pitch, a sales or launch deck, a product demo, a team update or a talk. One line per file. Written by Ultimatum; the topic list was checked against UI UX Pro Max's slides references (MIT), and none of its text, data or scripts are used. The house rules (`../../website/design-rules.md`) and the slop list (`../design-review-qa/slop-tells.md`) apply to slides as much as to pages.

## Reading order

1. `story.md`: pick the deck type, write the one-sentence point, then the arc and the slide list before any design.
2. `slides.md`: the slide grid, type sizes for a room and for a screen share, the dozen layouts most decks need, and colour.
3. `charts.md`: choosing a chart for one message, and making that message the first thing seen.
4. `build.md`: building the deck as one HTML file, speaker notes, exporting to PDF or PowerPoint, and checking it with `deck_check.py`.

`later.md` lists what this folder leaves out and why.

## When not to read this

- The owner has a company template in PowerPoint, Keynote or Google Slides: fill that template and use only `story.md` and `charts.md`.
- One social image or banner, not a deck: `../identity/identity-kit.md`.
