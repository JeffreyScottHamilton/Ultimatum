# Timeline: working back from the date

Put the event date at the bottom and work up. Each window lists tasks, an owner and the one number to watch. "Owner" is the organiser unless a helper is named; "manager" means this session drafts it for the organiser's yes. Windows are rules of thumb, not requirements.

## 8 weeks or more before

| Task | Owner | Notes |
|---|---|---|
| Intake and brief approved | Manager, organiser | `intake.md` |
| Venue or online platform confirmed in writing | Organiser | Capacity, access, times, cancellation terms |
| Speakers or hosts confirmed | Organiser | Names, bios, photos, consent to use them |
| Pre-announce checks | Organiser, manager | `launch-checklist.md` |
| Sign-up tool chosen and set up in test mode | Manager, organiser | `tickets-and-signups.md` |
| Event page drafted | Manager | Website team |
| Partners and communities listed | Manager | Who reaches the audience already |

Number to watch: none yet; readiness of the checklist.

## 4 weeks before

| Task | Owner | Notes |
|---|---|---|
| Announcement: page live, sign-ups open | Organiser's yes | Publish gate |
| Email to own list | Organiser's yes | One clear button |
| Announcement posts | Manager drafts, organiser approves | `promotion.md` |
| Partner and community outreach | Organiser | A ready-to-paste blurb and image for each |
| Local listings submitted | Manager drafts | Many need two or more weeks' notice: check each one |

Number to watch: sign-ups per day in the first week, and where they came from.

## 2 weeks before

| Task | Owner | Notes |
|---|---|---|
| Line-up or detail reveal | Manager drafts | One new reason to come per post |
| Early-bird ends, if used | Organiser | Close it on the stated date; do not extend silently |
| Social proof post | Manager drafts | Real quotes or photos with permission only |
| Run sheet first draft | Manager | `day-of.md` |
| Volunteers or helpers briefed | Organiser | Roles and times |

Number to watch: sign-ups against capacity; if under half, add one push (a partner mail, a direct invitation round).

## Launch week (the last 7 days)

| Task | Owner | Notes |
|---|---|---|
| "Last places" or "one week to go" post, only if true | Organiser's yes | Honest urgency only |
| Reminder to registrants with practical details | Organiser's yes | Time, place, what to bring, access |
| Supplies, materials, food ordered | Organiser | Check locally for food rules |
| Online tech rehearsal | Organiser, host | Links, sound, screen share, recording |

Number to watch: confirmed attendees and the waitlist.

## The day before

- Final reminder to registrants: start time, address or link, how to get in, a contact for problems.
- Run sheet printed or shared; backups named.
- Check-in list exported (kept off Git and out of chat logs).
- Weather or travel notice if relevant.

## The day

- Follow `day-of.md`. One person answers messages.
- Post only what was approved; live posts need the organiser's yes, and people in photos need to have agreed.

## The week after

- Thank-you within 48 hours, feedback form, recording if consented: `after-the-event.md`.
- Results review and `ult social --results "<what was measured>"`.

## Compressed plan (under 4 weeks)

Combine windows and drop what does not fit. Always tell the organiser what was cut.

| Days left | Do | Cut |
|---|---|---|
| 21-28 | Brief, checklist, page and sign-ups in a few days; announce at once to the list and partners | Line-up reveals spread over weeks; early-bird |
| 14-20 | Announce to list, partners and communities in the same week; one reminder post a week | Local press; most listings with long lead times |
| 7-13 | Direct invitations, own list, one partner; one social post and one reminder | Paid promotion, video production beyond a short clip |
| Under 7 | Personal invitations and the existing list only; simple sign-up form | Everything else; consider moving the date if the goal is a full room |

If the goal cannot be met in the time left, say so plainly and offer two options: a smaller goal for this date, or a later date.
