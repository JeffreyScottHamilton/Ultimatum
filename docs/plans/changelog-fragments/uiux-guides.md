Added UI UX Pro Max guides for website builds: 16 reference files, an index and a later list under skills/website/references/craft/ui-ux-pro-max/, written in our own words from the topics of the brand, design-system and ui-styling skills in nextlevelbuilder/ui-ux-pro-max-skill (MIT; ui-styling Apache-2.0). No text, code or fonts were taken.
Brand: the build order, voice and messaging, palette and type spec, logo use, asset library, approval and audit, and a fill-in guidelines file; facts are checked against hallmark/brand-truth.md rather than repeated.
Design system: primitive, semantic and component token layers, states and variants, and spec sheets for seven components.
Adds a starter token file under data/design-own/tokens/ and tools/build_tokens.py (stdlib only), which writes a plain CSS template and a Tailwind v4 @theme template and fails if any of 14 contrast pairs drops below its WCAG 2.2 floor, in light or dark. Both templates were compiled with Tailwind 4.3.5 and rendered in Chromium.
UI styling: shadcn/ui components, theming and accessibility; Tailwind v4 utilities, responsive layout, container queries and customisation (the source's v3 material rebuilt for v4); and a canvas guide for posters and single images, with fonts linked rather than bundled.
Slides, banners, logo, icon and identity design, the canvas fonts and the source's scripts are not adopted; later.md lists them. New test: tests/test_uiux_guides.py.
