# Routes when no kind plugin is installed

Each kind has its own Launch plugin with deeper steps: `ultimatum-website-launch`, `ultimatum-ecommerce-launch`, `ultimatum-app-launch`. If the user's kind is installed, hand over to it. If not, use the short notes below, and say once that installing that kind's plugin adds deeper intake, page and launch checklists:

```
/plugin install ultimatum-<kind>-launch@ultimatum
```

## Website (local business, service, portfolio, creator)

- Goal: one action (call, book, enquire). Every page leads there.
- Size: one page for a single offer; 4 to 6 pages (home, services, about, proof, contact) when there are several services or areas.
- Host on a simple static host or the builder the owner already pays for. The owner buys the domain in their own account.
- Local search: a claimed business listing with the same name, address and phone as the site; ask for reviews after each job.
- Video: Brand Film usually fits a people-led business.

## E-commerce (online store)

- Platform: a hosted store builder for most first stores; a self-hosted store only when the owner already runs that stack. Theme licences: check the vendor's terms before reuse (check before relying).
- Before launch: payments in test mode, then one real test order and refund; shipping zones; refund, privacy, terms and shipping policies.
- Product pages: consistent photos, clear titles, honest descriptions, variants that match stock.
- Video: Motion Graphics for product features and offers; Brand Film for a maker's or founder's story.

## App (web app, mobile app, software, subscription)

- Path: waitlist → beta → public launch; pick the stage at intake.
- Site: landing page with one call to action, a pricing page, docs or help.
- Billing provider in test mode first; trust pages (privacy, terms, security) before sign-ups open.
- Code work on the product itself goes to `ultimatum:work`; auth and billing get its security review.
- Video: Motion Graphics for demos and features; Brand Film for the mission or founder story.

Prices, fees and platform terms change: confirm on the vendor's own page.
