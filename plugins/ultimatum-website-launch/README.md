# Ultimatum Website Launch

A launch manager for small business, local service, restaurant or cafe, salon, clinic, trades, agency or consultant, coach, portfolio, creator and personal-brand sites, usually aimed at bookings, calls or enquiries. It runs the shared teams from Ultimatum Launch and every spend, post, publish and deploy waits for your yes.

It needs the core `ultimatum` plugin and the base `ultimatum-launch` plugin.

## Install

```
/plugin marketplace add JeffreyScottHamilton/Ultimatum
/plugin install ultimatum@ultimatum
/plugin install ultimatum-launch@ultimatum
/plugin install ultimatum-website-launch@ultimatum
```

## Start

Say "help me launch a website for my salon" in chat, or type `/ultimatum-website-launch:launch <what you are launching>`. Progress is kept in the project (`ult launch --kind website --root .` shows steps, approvals and the next action), so you can stop and resume.

## What it adds over the base manager

- Intake questions for local and small sites: the one action visitors should take, service area, hours, proof, existing listings and booking tool.
- A route guide: one page or 4-6 pages, which host or builder fits, domain and business email, and which video style suits a local or people-led business.
- Page-by-page anatomy, trust signals, local SEO (Google Business Profile, consistent name, address and phone, service-area pages, reviews), schema markup and accessibility basics.
- Playbooks by business type (restaurant, salon, clinic, trades, consultant, portfolio, studio): the main action, must-have pages, proof, video style and common mistakes for each.
- A copy guide: headline patterns, button wording, service and about page templates, and how to use reviews honestly.
- A launch checklist: forms and booking tested end to end, phone links, maps, mobile speed, call and booking events, domain, SSL and email, a launch-week plan and first-30-days metrics.
- Hand-offs to the shared teams (`ultimatum-launch:business`, `website`, `social-media`, and the video skills) with the right notes pasted in.

Prices, fees and vendor policies in the guides are marked "check before relying". Confirm them on the vendor's own page.
