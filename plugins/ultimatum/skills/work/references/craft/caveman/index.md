# Caveman craft: short answers that keep the facts

Read when choosing which caveman file to open: terse chat, short commits and reviews, compressing a memory file, or a narrow task stance.

Rebuilt from the ideas in JuliusBrussee/caveman at commit 47c61be (Apache-2.0). All wording and code here are ours. The base rule lives in `../../context-efficiency.md` § 2. Terse voice (chat prose only); these files go deeper.

- `terse-voice.md`: the three levels, what is never cut, when to switch back to full sentences, and the check before sending.
- `terse-artifacts.md`: short commit messages, one-line review comments and fixed reply shapes for helpers.
- `compress-memory.md`: shrinking a CLAUDE.md or notes file without losing an instruction, with a checker script.
- `task-stances.md`: the simplicity ladder, and when to stop for investigate, fix, build, refactor, migrate and verify tasks.
