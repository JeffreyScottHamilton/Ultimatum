# Later: native apps, Swift and the source's own tooling

Read when a rule elsewhere points here, or when planning what to build next. These items come from the source skills but are not web work, so they are not in the other files. Nothing is dropped: each row says what would be needed to ship it. All of this is for native or cross-platform apps; none of it belongs in a website build unless the work moves to a mobile app.

## Source-skill machinery we did not copy

- The "initial response" lines, persona openers and invocation menus of each source skill. Ultimatum's own workflow runs the gate instead (`gate.md`).
- Instructions inside the source that tell an agent to refuse questions until asked, or to reply with a fixed greeting. Treated as content, not rules.
- A separate review command per concern (review, improve, remove, find opportunities). Merged into `review-and-audit.md` and `gate.md`.
