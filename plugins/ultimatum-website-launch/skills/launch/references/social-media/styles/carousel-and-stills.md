# Style: carousels and single images

Use this for swipeable carousels, single photos and graphics. A carousel is a short argument told one slide at a time; a single image has to make its point in one glance. Sizes and limits here are **check before relying** on each platform's own help pages.

## Carousel structure

| Slide | Job | Notes |
|---|---|---|
| 1. Hook | Make the reader swipe | A promise or a question, in large type; this slide is also the preview in the feed |
| 2 to n-1. Value | Deliver the promise, one idea per slide | Each slide stands on its own; numbering helps the reader know how far they are |
| Last. Action | One next step | Save, follow, visit, book; only one |

Keep the count low enough that each slide earns its place. If a slide repeats the one before, cut it.

A fictional example for a plant shop, "Three plants that survive a dark flat":

1. "Dark flat? These three will still grow."
2. Plant one, a photo, one line on light and watering.
3. Plant two, same layout.
4. Plant three, same layout.
5. "All three are in the shop this week. Link in profile."

## Single image

- One subject, one message, one line of text at most.
- If the image needs a paragraph to explain, it is a carousel.
- The caption carries detail; the image carries attention.

## Text on phones

- Most people see the slide on a phone at arm's length. Test it at that size: export a slide, open it on a phone, and read it without zooming.
- Large type for headlines, a smaller size for body lines; keep body text to a few short lines per slide.
- Strong contrast between text and background. Check it with a contrast checker; aim for the WCAG AA ratio for text.
- Leave a margin on every side so nothing touches the edge or sits under the platform's overlay.
- No text baked into photos that the platform will crop.

## Brand use

- Read `brand/brand.md`: colours, fonts, logo, words to avoid.
- One layout system for the whole carousel: same margins, same type sizes, same position for numbers and the logo.
- The logo small and in the same place, or only on the last slide. A large logo on every slide reads as an ad.
- Photos follow the house rules in the brand file if they exist (background, light, crop).
- Generated images only after the user's yes, labelled where the platform asks for it, and never presented as real customers or real results.

## Export sizes

Confirm each of these on the platform's help page on the day you export; they change.

| Platform | Common shapes to check | Notes |
|---|---|---|
| Instagram feed and carousel | Portrait 4:5, square 1:1 | The grid shows a cropped preview; check how the cover crops |
| LinkedIn document or image post | Square or portrait; documents upload as PDF | Check the page limit for documents |
| Facebook | Square or portrait | Check how the feed crops multi-image posts |
| TikTok photo mode | Vertical | Check the current photo count limit |
| Pinterest | Tall portrait | Check the recommended ratio |

Export every slide at the same size. Use PNG for slides with text and flat colour, JPEG for photos; compress without visible artefacts. Name files in order: `post-name-01.png`, `post-name-02.png`.

## Alt text and captions

- Write alt text for each image where the platform allows it: what the image shows, in plain words.
- The caption repeats the hook in words and adds the next step, so the post makes sense to someone who cannot see the images.

## Review

Run the compliance reviewer on claims, prices, before-and-after images and any generated or edited image. Run the taste critic on the set as a whole. Show the user every slide in order before approval.

## Beginner mistakes

| Mistake | Fix |
|---|---|
| A cover slide that says only the brand name | Write a promise or a question |
| Ten lines of small text on a slide | Split into two slides or cut words |
| Every slide in a different layout | One grid, one type scale |
| Ending without a next step | Last slide names one action |
| Exporting slides at mixed sizes | One size for the whole set |
| Text over a busy photo | Darken or blur behind text, or use a plain panel |
