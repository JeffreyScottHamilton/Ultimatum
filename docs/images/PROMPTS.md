# Workflow image prompts

Paste the **style block** first, then one image block, into ChatGPT (one image per chat works best). Save each result under the file name shown, in this folder.

## Style block (paste with every image)

```
Make a workflow diagram as a flat, hand-made-looking print graphic, the way a designer would draw it in Figma for a printed product manual. It must not look AI-generated.

Style:
- Off-white paper background (#F5F2EA), black ink lines 2px, one accent colour only: signal orange (#FF5A1F). No other colours.
- Plain rectangles with square corners for steps, small filled orange circles for "you approve" stops, straight arrows with simple triangle heads. Lines meet at right angles.
- Type: one plain sans-serif like Helvetica or Inter, black, left-aligned. Step titles bold, notes regular and small. Spell every word exactly as written below; add no other text.
- Strict grid, generous white space, everything aligned. Landscape 16:9.
- Flat only. No gradients, glow, shadows, 3D, glass, neon, sparkles, light rays, bokeh, textures, stock-art icons, robots, brains, people, hands, or futuristic UI. No decorative swirls. No logo.
- Looks like a clean technical diagram printed in ink, slightly imperfect line weight is fine.
```
