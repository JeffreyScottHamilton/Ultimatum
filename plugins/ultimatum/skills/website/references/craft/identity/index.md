# Identity craft: index

Read when a site needs a logo, a favicon and app icons, or the rest of a small identity kit (cards, social images, signage). One line per file. Written by Ultimatum from primary sources; the topic list was checked against UI UX Pro Max's logo and identity references (MIT), none of its text or generators are used. The house rules (`../../website/design-rules.md`) win on any conflict.

## Reading order

1. `logo.md`: which kind of mark fits the business, how to draw and test it, and the files to hand over.
2. `logo-colour.md`: picking colours for the mark, the one-colour test, and contrast where it matters.
3. `ai-logo.md`: using an image model for logo ideas without ending up with an unusable or unprotectable mark.
4. `identity-kit.md`: favicons, app icons, social images, print pieces and how to organise the files.

`later.md` lists what this folder leaves out and why.

## When not to read this

The owner already has a logo: use it as given, ask for the vector file, and only read `identity-kit.md` for the icon and social sizes. Never redraw an existing logo unasked.
